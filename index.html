                    ❓ Help with Tokens & Features
                

                
            

            

                
Tokens allow you to dynamically extract and manipulate values when running transformations. They can be used in both the Attribute Name and Expression Value fields by wrapping them in curly braces {...}.

                
                

                    

                        
{var["name"]} / {const["name"]} / {counter["name"]}

                        
Extracts data from a previously declared Variable, Constant, or Counter in the current or parent group. Variables are destroyed when leaving their group.

                        
Example: {var["user_id"]}

                        
Counters return their current value and increment immediately after evaluation.

                    


                    

                        
{attribute[n]} / {attribute["name"]} / {att["name"]}

                        
Extracts an attribute from the currently evaluated element by numerical index or exact quoted key. (att is a valid shorthand alias).

                        
Example: id_{attribute["id"]} → id_101

                        
Example: {att[-0]} → Returns the last attribute value.

                    


                    

                        
{child[n]} / {child["tag"][n]}

                        
Extracts inner text of direct children or chains nested commands. Use negative indices like -0 to count from the end backwards.

                        
    
                            
  • {child[0]}: Gets the first child's text.
    • 
                            
  • {child[-0]}: Gets the last child's text.
    • 
                            
  • {child["author"][1]}: Gets 2nd child of exact type "author".
    • 
                            
  • {child[0](att["id"])}: Retrieves the "id" of the 1st child node.
    • 
                        

                    

                    
                    

                        
{ancestor[n]} / {ancestor["tag"][n]} / {parent(...)}

                        
Evaluates any token in the context of an ancestral element. parent(...) is kept for backward compatibility and is equivalent to ancestor[0](...).

                        
    
                            
  • {ancestor[0](att["id"])}: Gets "id" of the direct parent.
    • 
                            
  • {ancestor[1](att["id"])}: Gets "id" of the grandparent.
    • 
                            
  • {ancestor["section"][0](att["name"])}: Gets "name" of the first ancestor of type "section".
    • 
                        

                    


                    

                        
{value}

                        
Available only when your XPath targets an attribute directly (e.g., //@id). Inserts the value of that matched attribute.

                    


                    
Value Modifiers

                    
                    

                        
token[start:take] (Slicing)

                        
Extract substrings. Append to any evaluated token. Use negative start to base calculation from the end backwards (e.g., -0 starts directly at the end).

                        
Example: {att["date"][3:7]} takes 7 characters starting at index 3.

                        
Example: {value[-0:4]} on "hello" starts at the end, returning backwards giving "llo".

                    


                    

                        
token["separator":start:take] (Splitting)

                        
Split strings into arrays by separator, slice the array with start and take, then join back.

                        
Example: {att["path"]["/":0:2]} splits by "/" and keeps the first 2 segments.

                    


                    
Other Features

                    
    
                        
  • Groups: Organize multiple rules into foldable named groups. Can be nested inside other groups.
    • 
                        
  • Shifting: Use ◀ and ▶ to move rules in and out of nested groups.
    • 
                        
  • Prepending: New rules added to a scope appear at the top.
    • 
                        
  • IF/ELSE Conditions: Set blocks to evaluate dynamically based on token results. False paths skip the block.
    •
